An end-to-end sports analytics pipeline and interactive web dashboard designed to extract, filter, and visualize Pittsburgh Steelers player performance metrics—comparing home vs. away splits, 
position-level efficiency, and historical win-loss rates.

---

## 🏗️ Repository Architecture

```text
SteelersStats/
├── etl_pipeline.py        # Python ETL script for data extraction, filtering, and cleaning
├── main.py                # Core query logic, custom filters, and statistical aggregations
├── steelers_stats.csv     # Processed dataset generated by the Python pipeline
└── steelersfrontend/      # Vite + React interactive dashboard for exploring metrics

⚙️ How It Works
1. Python ETL & Filtering Pipeline (etl_pipeline.py & main.py)
Data Extraction & Cleaning: Parses raw player records, validates data types, removes duplicate entries, and standardizes schema keys (player, position, home_wins, home_losses, win_percentage).

Custom Analytical Queries: Implements filtering by position, home/away performance splits, and top-performer ranking functions.

Structured Output: Exports the clean, analysis-ready dataset to steelers_stats.csv.

2. Interactive Visualization Frontend (steelersfrontend/)
Built with Vite and React for fast client-side filtering and responsive metric inspection.

Consumes the processed dataset to display player breakdowns, win-rate comparisons, and positional insights.

🚀 Getting Started
Prerequisites
Python 3.10+ (with pandas installed)

Node.js 18+ & npm

# Install dependencies (if needed)
pip install pandas

# Execute the ETL pipeline to regenerate steelers_stats.csv
python etl_pipeline.py

# Run standalone CLI analytics/filters
python main.py


cd steelersfrontend
npm install
npm run dev
